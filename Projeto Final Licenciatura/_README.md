Passos para correr a aplicação:

* Criar uma base de dados no MySQL Workbench chamada **barter**, com password **root**.
* Importar os datasets inseridos em /03\_Implementacao/ProcessamentoDados/Datasets, chamados **deals\_limpos.csv** e **creators\_limpos.csv**, de modo a criar duas tabelas, **deals** e **creators**, respetivamente.
* Editar o ficheiro .bat em /03\_Implementacao chamado **run\_dealrank.bat,** alterando os paths neste incluídos para o path da aplicação /DealRank/src na sua máquina.
* Correr o ficheiro **run\_dealrank.bat** e colocar num navegador web, o URL que irá aparecer na consola.
